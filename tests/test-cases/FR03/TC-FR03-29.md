# TC-FR03-29

## Requirement ID
FR03

## Module / Test type / Technique
Forgot password and password reset (two steps) / Functional / Boundary Value Analysis

## Test design source
test-design/BVA-FR03.md

## Coverage
| Coverage Type | Covered IDs |
|---|---|
| Boundary Value Analysis | FR03_MAXM_03 |

## Detail
| ID | Partition Tested | OTP (Input) | Mật khẩu mới (Input) | Xác nhận mật khẩu (Input) | Expected Output |
|---|---|---|---|---|---|
| FR03_MAXM_03 | Độ dài Mật khẩu mới = Max - 1 (254 ký tự) | `123456` *(mã đúng)* | `A` + `b` (lặp lại 250 lần) + `1!` | `A` + `b` (lặp lại 250 lần) + `1!` | - Đặt lại mật khẩu thành công (O9) |

## Preconditions
1. Người dùng đã hoàn thành Bước 1 (Gửi OTP thành công cho email `test@eshop.com`).
2. Người dùng đang ở giao diện Đặt lại mật khẩu (Bước 2).

## Test data
| Field | Value |
|---|---|
| OTP | Mã OTP 6 chữ số hợp lệ được sinh ra ở Bước 1 |
| Mật khẩu mới | A + 250 ký tự 'b' + 1! (tổng độ dài 254 ký tự) |
| Xác nhận mật khẩu mới | A + 250 ký tự 'b' + 1! |

## Test steps
1. Nhập mã OTP hợp lệ vào trường OTP.
2. Nhập mật khẩu mới dài 254 ký tự nêu trên vào trường Mật khẩu mới.
3. Nhập mật khẩu mới dài 254 ký tự nêu trên vào trường Xác nhận mật khẩu mới.
4. Nhấp nút "Đặt lại mật khẩu".

## Expected results
1. Đặt lại mật khẩu thành công, hiển thị thông báo thành công.
2. Mật khẩu mới được cập nhật vào hệ thống.

## Actual results
1. Thất bại: Nhập mật khẩu hợp lệ thực sự có chứa ký tự đặc biệt, hệ thống báo lỗi mật khẩu quá yếu (do lỗi regex khoảng trắng). Không thể đặt lại thành công.

## Status
Failed
