# TC-FR03-32

## Requirement ID
FR03

## Module / Test type / Technique
Forgot password and password reset (two steps) / Functional / Boundary Value Analysis

## Test design source
test-design/BVA-FR03.md

## Coverage
| Coverage Type | Covered IDs |
|---|---|
| Boundary Value Analysis | FR03_MINM_04 |

## Detail
| ID | Partition Tested | OTP (Input) | Mật khẩu mới (Input) | Xác nhận mật khẩu (Input) | Expected Output |
|---|---|---|---|---|---|
| FR03_MINM_04 | Số chữ hoa trong Mật khẩu mới = Min - 1 (0 chữ hoa) | `123456` *(mã đúng)* | `abc12345!` | `abc12345!` | - Đặt lại mật khẩu thất bại, thông báo lỗi thiếu chữ hoa (O10) |

## Preconditions
1. Người dùng đã hoàn thành Bước 1 (Gửi OTP thành công cho email `test@eshop.com`).
2. Người dùng đang ở giao diện Đặt lại mật khẩu (Bước 2).

## Test data
| Field | Value |
|---|---|
| OTP | Mã OTP 6 chữ số hợp lệ được sinh ra ở Bước 1 |
| Mật khẩu mới | abc12345! (0 chữ cái viết hoa) |
| Xác nhận mật khẩu mới | abc12345! |

## Test steps
1. Nhập mã OTP hợp lệ vào trường OTP.
2. Nhập `abc12345!` vào trường Mật khẩu mới.
3. Nhập `abc12345!` vào trường Xác nhận mật khẩu mới.
4. Nhấp nút "Đặt lại mật khẩu".

## Expected results
1. Đặt lại mật khẩu thất bại.
2. Hiển thị thông báo lỗi mật khẩu mới không hợp lệ (ví dụ: "Mật khẩu phải chứa ít nhất 1 chữ cái viết hoa").
3. Giao diện được giữ nguyên ở Bước 2.

## Actual results
1. Thành công: Nhập mật khẩu thiếu chữ hoa, hệ thống báo lỗi mật khẩu quá yếu.

## Status
Passed
