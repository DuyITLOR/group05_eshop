# Title

[HW04][BUG][FR-09][Discount Coupon] Checkout total có thể chỉnh sửa trực tiếp

# Body

## Found by Test Case

`FR09-TC-016`

## Related Requirements

`FR09-R12` — Checkout total phải derive từ cart và không user-editable.

## Severity / Priority

Severity: `High`; Priority: `P1`.

Reason: trusted financial input có thể bị user sửa và được dùng trong coupon/checkout request path; không khẳng định completed fraudulent order ngoài evidence.

## Environment

EShop FR-09, frontend `http://localhost:5173`, backend `http://localhost:3000`, Chromium/Firefox/WebKit; versions/OS/viewport/zoom/SUT commit: `NOT_RECORDED_AT_EXECUTION`. Data: `FR09-DATA-005` seed total 4000000.

## Preconditions

Authenticated session; cart có seed product quantity 1; Checkout total ban đầu 4000000.

## Steps to Reproduce

1. Mở Checkout từ seed cart.
2. Focus total control.
3. Nhập value khác trực tiếp.
4. Quan sát control/value.

## Expected Result

Total derive từ cart và không thể user-edit; coupon context giữ trusted total 4000000.

## Actual Result

Total là editable number input và chấp nhận user-entered value trên cả ba browser.

## Reproducibility

`Always` trên ba browser.

## Impact

User kiểm soát financial value dùng cho coupon eligibility/calculation, tạo data-integrity risk.

## Browser Coverage

Chromium, Firefox, WebKit: `FAILED` — `PRODUCT_DEFECT`. Xem `docs/execution-results/fr-09-cross-browser-summary.md`.
