# Title

[HW04][BUG][FR-09][Discount Coupon] User chưa đăng nhập vẫn sử dụng được Checkout coupon flow

# Body

## Found by Test Case

`FR09-TC-013`

## Related Requirements

`FR09-R11` — chỉ authenticated user được tiến hành Checkout.

## Severity / Priority

Severity: `Medium`; Priority: `P2`.

Reason: unauthenticated user dùng được Checkout coupon UI, nhưng runtime chưa chứng minh successful payment/order creation.

## Environment

EShop FR-09, direct route `http://localhost:5173/checkout`, backend `http://localhost:3000`, Chromium/Firefox/WebKit; versions/OS/viewport/zoom/SUT commit: `NOT_RECORDED_AT_EXECUTION`; fresh unauthenticated context.

## Preconditions

Fresh browser context không có JWT/user session.

## Steps to Reproduce

1. Truy cập trực tiếp `/checkout`.
2. Chờ shell/`main` render.
3. Nhập code vào coupon input và kiểm tra Apply action.

## Expected Result

User không được tiến hành Checkout; functional coupon application UI không usable.

## Actual Result

Checkout render cho unauthenticated user; coupon input visible và Apply action usable.

## Reproducibility

`Always` trên ba browser.

## Impact

Checkout/UI access-control prerequisite bị vi phạm. Đây là defect riêng với missing JWT enforcement tại coupon API.

## Browser Coverage

Chromium, Firefox, WebKit: `FAILED` — `PRODUCT_DEFECT`. Xem `docs/execution-results/fr-09-cross-browser-summary.md`.
