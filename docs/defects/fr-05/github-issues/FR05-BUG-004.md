# Title

[HW04][BUG][FR-05][Product Listing] Event-handler markup được thực thi khi phản chiếu search input

# Body

## Found by Test Case

`FR05-TC-012`

## Related Requirements

`FR05-R05`; `SEC-04`

## Severity / Priority

Severity: `High`; Priority: `P1`.

Reason: Mọi browser đều chứng minh reflected event-handler markup được thực thi với real dialog và `img[onerror]` element.

## Preconditions

Public home page khả dụng; controlled product-search response là empty array; dialog observer đã được attach.

## Steps to Reproduce

1. Mở public home page.
2. Attach dialog observer.
3. Submit `<img src=x onerror=alert('FR05-XSS')>`.
4. Dismiss các dialog đã capture và kiểm tra reflected DOM.

## Expected Result

Payload vẫn là safe text; không mở dialog và không có input-derived `img[onerror]`.

## Actual Result

Chromium capture 2 dialog, Firefox capture 2, WebKit capture 1; mọi browser đều có một `img[onerror]`.

## Reproducibility

`Always`

Lỗi thực thi được reproduce trên cả ba browser. Dialog count khác nhau theo browser nhưng mọi browser đều capture execution.

## Impact

Reflected input đi vào executable event-handler markup. Draft này chỉ nêu dialog/DOM behavior đã được chứng minh, không khẳng định remote code execution, data theft, account takeover hoặc broader compromise.
