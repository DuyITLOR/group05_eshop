## Preconditions

Public home page khả dụng; controlled product-search response là empty array.

## Steps to Reproduce

1. Mở public home page.
2. Submit `<b>FR05 HTML Keyword</b>`.
3. Kiểm tra scoped reflected-keyword region.

## Expected Result

Payload giữ nguyên literal text và không tạo input-derived `b` element.

## Actual Result

Reflected region chứa một `b` element và render submitted keyword thành markup.

## Reproducibility

`Always`

Lỗi được reproduce nhất quán trên Chromium, Firefox và WebKit.

## Impact

User-controlled content có thể thay đổi reflected search presentation và vi phạm safe text rendering.
