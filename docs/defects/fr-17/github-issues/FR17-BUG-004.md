# Title

[HW04][BUG][FR-17][Coupon Management] Non-admin vẫn truy cập được Coupon Management

# Body

## Found by Test Case

`FR17-TC-016`

## Related Requirements

`FR17-R15` — Coupon Management chỉ dành cho `role='admin'`.

## Severity / Priority

Severity: `High`; Priority: `P1`.

Reason: valid non-admin session vẫn nhận usable privileged management control trên cả ba engines. Test không thực hiện create/delete nên không khẳng định unauthorized mutation.

## Environment

EShop FR-17 Web Admin tại `http://localhost:5174`, backend `http://localhost:3000`; Chromium, Firefox, WebKit. Browser versions, OS build, device, viewport, zoom và SUT commit: `NOT_RECORDED`. Setup: `FR17-SETUP-002`.

## Preconditions

Fresh browser context; runtime-verified non-admin JWT; no admin JWT.

## Steps to Reproduce

1. Establish controlled non-admin session.
2. Verify role khác `admin`.
3. Mở Web Admin.
4. Quan sát Coupon Management controls.

## Expected Result

Coupon list/create/delete controls không khả dụng cho non-admin.

## Actual Result

Web Admin hiển thị usable `Mã Giảm Giá` control trên Chromium, Firefox và WebKit; test không thực hiện create/delete.

## Reproducibility

`Always in final runs` trên cả ba engines.

## Impact

Non-admin tiếp cận privileged management surface trái role requirement; không khẳng định data mutation hoặc privilege escalation ngoài evidence.
