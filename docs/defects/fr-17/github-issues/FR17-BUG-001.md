# Title

[HW04][BUG][FR-17][Coupon Management] Required coupon fields không hiển thị ký hiệu *

# Body

## Found by Test Case

`FR17-TC-002`

## Related Requirements

`FR17-R16` — mỗi required coupon field phải có visible `*` indicator bên cạnh label.

## Severity / Priority

Severity: `Low`; Priority: `P3`.

Reason: thiếu required indicator vi phạm UI requirement và làm giảm field clarity/accessibility, nhưng không có evidence create flow bị chặn hoặc dữ liệu bị sai.

## Environment

EShop FR-17 Web Admin tại `http://localhost:5174`, backend `http://localhost:3000`; Chromium, Firefox, WebKit. Browser versions, OS build, device, viewport, zoom và SUT commit: `NOT_RECORDED`. Dataset: `FR17-DATA-002`.

## Preconditions

Valid admin session; Coupon Management create form visible.

## Steps to Reproduce

1. Đăng nhập Web Admin bằng valid admin account.
2. Mở Coupon Management.
3. Quan sát sáu required fields.
4. Kiểm tra visible associated `*` indicator.

## Expected Result

Cả sáu required field labels có visible `*` indicator bên cạnh.

## Actual Result

Không có visible associated label/labelled element chứa `*`; assertion fail từ field `code`.

## Reproducibility

`Always in final runs` trên Chromium, Firefox và WebKit.

## Impact

Admin thiếu visual cue về required fields; ảnh hưởng UI clarity và accessibility/usability.
