# TC_05 — Login sai mat khau lan thu 3 (trigger khoa tai khoan)

## Preconditions
- Ung dung EShop dang hoat dong tai `http://localhost:5173`
- Backend API dang chay tai `http://localhost:3000`
- Tai khoan `test@eshop.com` ton tai va **chua bi khoa**
- `failed_attempts = 2` (da sai 2 lan truoc do)

### Setup failed_attempts = 2
```bash
# Reset DB
cd backend && node database.js

# Dang nhap sai 2 lan
curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@eshop.com","password":"Wrong1!"}'

curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@eshop.com","password":"Wrong2!"}'
```

## Steps
1. Dam bao `failed_attempts = 2` cho tai khoan test
2. Truy cap trang Login
3. Nhap email va mat khau **sai** (lan thu 3)
4. Nhan nut Dang nhap
5. Kiem tra tai khoan da bi khoa

## Test Data

| Field | Value |
|-------|-------|
| Email | `test@eshop.com` |
| Password | `WrongPassword3!` |

## Expected Result
- He thong tra ve loi: thong bao chung "Email hoac mat khau khong dung"
- `failed_attempts` tang len **3** (A3: tang dung 1 don vi)
- Tai khoan **BI KHOA 30 giay** (A4: trigger lock)
- Cac lan login tiep theo trong 30s se bi reject voi loi "tai khoan bi khoa" (R3/A5)

### Verification
```bash
# Lan thu 3 — sai
curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@eshop.com","password":"WrongPassword3!"}'
# Expected: error + account locked

# Thu login ngay sau do (trong 30s) voi mat khau DUNG
curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@eshop.com","password":"Test1234!"}'
# Expected: van bi reject vi locked
```

## Mapping
- Decision Rule: R4b
- Condition Coverage: C1=T, C2=T, C3=F, C4=F
- State: failed_attempts = 2 truoc khi test
- Actions: A2 (error message), A3 (increment counter), A4 (lock account)
