# TC_03 — Login voi tai khoan dang bi khoa

## Preconditions
- Ung dung EShop dang hoat dong tai `http://localhost:5173`
- Backend API dang chay tai `http://localhost:3000`
- Tai khoan test da bi khoa (da dang nhap sai >= 3 lan lien tiep, trong vong 30 giay)

### Setup khoa tai khoan
```bash
# Dang nhap sai 3 lan de trigger lock
curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@eshop.com","password":"WrongPass1!"}'

curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@eshop.com","password":"WrongPass2!"}'

curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@eshop.com","password":"WrongPass3!"}'
```

## Steps
1. Dam bao tai khoan da bi khoa (failed_attempts >= 3, chua het 30s)
2. Truy cap trang Login
3. Nhap email va mat khau (dung hoac sai deu khong quan trong)
4. Nhan nut Dang nhap

## Test Data

**Test 3a — Mat khau sai khi locked:**

| Field | Value |
|-------|-------|
| Email | `test@eshop.com` |
| Password | `WrongPassword!` |

**Test 3b — Mat khau DUNG khi locked:**

| Field | Value |
|-------|-------|
| Email | `test@eshop.com` |
| Password | `Test1234!` |

## Expected Result
- Ca 2 truong hop (3a va 3b) deu tra ve **loi tai khoan bi khoa**
- Thong bao: tai khoan tam khoa, vui long cho 30 giay (hoac tuong tu)
- **KHONG** cho phep login du mat khau dung (C4 irrelevant)
- He thong khong check password khi account da locked

## Mapping
- Decision Rule: R3
- Condition Coverage: C1=T, C2=T, C3=T, C4=-
- Actions: A5 (account locked error)
