# TC_06 — Login thanh cong (Happy Path)

## Preconditions
- Ung dung EShop dang hoat dong tai `http://localhost:5173`
- Backend API dang chay tai `http://localhost:3000`
- Tai khoan `test@eshop.com` ton tai va **chua bi khoa**
- `failed_attempts = 0` (hoac < 3 va chua het 30s lock)

### Setup (neu can)
```bash
cd backend && node database.js   # Reset DB ve trang thai ban dau
```

## Steps
1. Truy cap trang Login
2. Nhap email hop le, ton tai trong he thong
3. Nhap mat khau **dung**
4. Nhan nut Dang nhap
5. Kiem tra login thanh cong

## Test Data

**Test 6a — User thuong:**

| Field | Value |
|-------|-------|
| Email | `test@eshop.com` |
| Password | `Test1234!` |

**Test 6b — Admin:**

| Field | Value |
|-------|-------|
| Email | `admin@eshop.com` |
| Password | `Admin123!` |

## Expected Result
- He thong tra ve **JWT Token** va thong tin user (A1)
- `failed_attempts` duoc **reset ve 0** (A6)
- Nguoi dung duoc redirect vao trang chinh cua he thong
- Token duoc luu phia client (localStorage/cookie)
- Cac request tiep theo gui kem header `Authorization: Bearer <token>`

### Verification
```bash
# Login thanh cong
curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@eshop.com","password":"Test1234!"}'
# Expected: {"token":"eyJ...", "user":{...}}

# Verify token hoat dong
curl http://localhost:3000/api/users/me \
  -H "Authorization: Bearer <token_from_above>"
# Expected: user profile data
```

## Mapping
- Decision Rule: R5
- Condition Coverage: C1=T, C2=T, C3=F, C4=T
- Actions: A1 (login success), A6 (reset counter)
