# TC_04 — Login sai mat khau (chua dat nguong khoa)

## Preconditions
- Ung dung EShop dang hoat dong tai `http://localhost:5173`
- Backend API dang chay tai `http://localhost:3000`
- Tai khoan `test@eshop.com` ton tai va **chua bi khoa** (failed_attempts < 2)
- Reset DB neu can: `node database.js`

## Steps
1. Truy cap trang Login
2. Nhap email hop le, ton tai trong he thong
3. Nhap mat khau **sai**
4. Nhan nut Dang nhap
5. Kiem tra response va trang thai `failed_attempts` trong DB

## Test Data

| Field | Value |
|-------|-------|
| Email | `test@eshop.com` |
| Password | `WrongPassword123!` |

### Verify failed_attempts (API/DB check)
```bash
# Login sai
curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@eshop.com","password":"WrongPassword123!"}'

# Kiem tra: failed_attempts phai tang dung 1 (khong phai 2)
```

## Expected Result
- He thong tra ve loi: thong bao chung "Email hoac mat khau khong dung"
- `failed_attempts` tang **dung 1 don vi** (A3)
  - Neu truoc do = 0 → sau = 1
  - Neu truoc do = 1 → sau = 2
- Tai khoan **CHUA** bi khoa (vi chua dat nguong 3)
- **KHONG** tiet lo rang password sai (chi thong bao chung)

## Mapping
- Decision Rule: R4a
- Condition Coverage: C1=T, C2=T, C3=F, C4=F
- State: failed_attempts < 2 truoc khi test
- Actions: A2 (error message), A3 (increment counter)
