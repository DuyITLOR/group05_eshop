## Detail
| ID | Test Objective | Transition Path | Expected Result |
|---|---|---|---|
| FR10-STT-08 | User/Admin hủy đơn hàng ở trạng thái confirmed | `confirmed` --(Cancel)--> `canceled` | Đơn hàng chuyển sang trạng thái `canceled` thành công |

## Preconditions
1. Đăng nhập tài khoản User test (`test@eshop.com` / `Test1234!`).
2. Có sẵn một đơn hàng test của User này ở trạng thái `confirmed`.

## Test data
| Field | Value |
|---|---|
| Tài khoản User | `test@eshop.com` / `Test1234!` |
| Mã đơn hàng | [Lấy ID đơn hàng confirmed thực tế] |

## Test steps
1. Gửi yêu cầu hủy đơn hàng qua endpoint `PUT /api/orders/:id/cancel` với header Authorization hợp lệ.
2. Kiểm tra trạng thái đơn hàng trong Database.

## Expected results
1. Response trả về HTTP status 200 OK.
2. Response body chứa thông báo `"Order canceled successfully"`.
3. Trạng thái đơn hàng trong Database được cập nhật thành `canceled`.

## Actual results
1. Response trả về HTTP status 200 OK.
2. Response body: `{"message":"Order canceled successfully"}`.
3. Trạng thái đơn hàng trong Database đã chuyển sang `canceled`.

## Status
Passed
