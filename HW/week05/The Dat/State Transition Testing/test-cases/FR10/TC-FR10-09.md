## Detail
| ID | Test Objective | Transition Path | Expected Result |
|---|---|---|---|
| FR10-STT-09 | Chặn Admin xác nhận đơn hàng khi đơn hàng đang được giao | `shipping` --(Confirm)--> `Chặn` | Hệ thống báo lỗi 400, trạng thái giữ nguyên là `shipping` |

## Preconditions
1. Đăng nhập tài khoản Admin (`admin@eshop.com` / `Admin123!`).
2. Có sẵn một đơn hàng test ở trạng thái `shipping`.

## Test data
| Field | Value |
|---|---|
| Tài khoản Admin | `admin@eshop.com` / `Admin123!` |
| Mã đơn hàng | [Lấy ID đơn hàng shipping thực tế] |
| Trạng thái đích | `confirmed` |

## Test steps
1. Gửi yêu cầu cập nhật trạng thái đơn hàng qua endpoint `PUT /api/admin/orders/:id/status` với body:
```json
{
  "status": "confirmed"
}
```
2. Kiểm tra trạng thái đơn hàng trong Database.

## Expected results
1. Response trả về HTTP status 400 Bad Request.
2. Response body chứa thông báo lỗi chuyển trạng thái không hợp lệ.
3. Trạng thái đơn hàng trong Database giữ nguyên là `shipping`.

## Actual results
1. Response trả về HTTP status 400 Bad Request.
2. Response body: `{"error":"Invalid state transition from shipping to confirmed"}`.
3. Trạng thái đơn hàng trong Database giữ nguyên là `shipping`.

## Status
Passed
