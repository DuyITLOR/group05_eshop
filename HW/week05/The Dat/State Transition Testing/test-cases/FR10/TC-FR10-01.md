## Detail
| ID | Test Objective | Transition Path | Expected Result |

## Preconditions
1. Đăng nhập tài khoản Admin (`admin@eshop.com` / `Admin123!`).
2. Có sẵn một đơn hàng test ở trạng thái `pending`.

## Test data
| Field | Value |
|---|---|
| Tài khoản Admin | `admin@eshop.com` / `Admin123!` |
| Mã đơn hàng | [Lấy ID đơn hàng pending thực tế] |
| Trạng thái đích | `confirmed` |

## Test steps
1. Gửi yêu cầu cập nhật trạng thái đơn hàng qua endpoint `PUT /api/admin/orders/:id/status` với body:
```json
{
  "status": "confirmed"
}
```
2. Kiểm tra trạng thái đơn hàng trong Database.

## Expected results
1. Response trả về HTTP status 200 OK.
2. Response body chứa thông báo `"Order status updated"`.
3. Trạng thái đơn hàng trong Database được cập nhật thành `confirmed`.

## Actual results
1. Response trả về HTTP status 200 OK.
2. Response body: `{"message":"Order status updated"}`.
3. Trạng thái đơn hàng trong Database đã chuyển sang `confirmed`.

## Status
Passed
