## Detail
| ID | Test Objective | Transition Path | Expected Result |
|---|---|---|---|
| FR10-STT-20 | Chặn hủy lại đơn hàng đã bị hủy trước đó | `canceled` --(Cancel)--> `Chặn` | Hệ thống báo lỗi 400, trạng thái giữ nguyên là `canceled` |

## Preconditions
1. Đăng nhập tài khoản User test (`test@eshop.com` / `Test1234!`).
2. Có sẵn một đơn hàng test ở trạng thái `canceled`.

## Test data
| Field | Value |
|---|---|
| Tài khoản User | `test@eshop.com` / `Test1234!` |
| Mã đơn hàng | [Lấy ID đơn hàng canceled thực tế] |

## Test steps
1. Gửi yêu cầu hủy đơn hàng qua endpoint `PUT /api/orders/:id/cancel` với header Authorization hợp lệ.
2. Kiểm tra trạng thái đơn hàng trong Database.

## Expected results
1. Response trả về HTTP status 400 Bad Request.
2. Response body chứa thông báo lỗi.
3. Trạng thái đơn hàng trong Database giữ nguyên là `canceled`.

## Actual results
1. Response trả về HTTP status 400 Bad Request.
2. Response body: `{"error":"Cannot cancel this order."}`.
3. Trạng thái đơn hàng trong Database giữ nguyên là `canceled`.

## Status
Passed
