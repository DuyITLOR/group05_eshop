|---|---|---|---|
| FR10-UCT-08 | Hệ thống chặn việc cập nhật trạng thái nhảy cóc không qua các bước trung gian (VD: pending thẳng lên shipping) | EF3: EF3.1 -> EF3.2 | Yêu cầu bị chặn, trả về lỗi, trạng thái giữ nguyên là `pending` |

## Preconditions
1. Đăng nhập tài khoản Admin (`admin@eshop.com` / `Admin123!`).
2. Có đơn hàng test ở trạng thái `pending`.
3. Đang ở trang Admin / Quản lý đơn hàng hoặc sử dụng công cụ gửi request API.

## Test data
| Field | Value |
|---|---|
| Tài khoản Admin | `admin@eshop.com` / `Admin123!` |
| Trạng thái hiện tại | `pending` |
| Trạng thái muốn chuyển | `shipping` hoặc `delivered` |

## Test steps
1. Đăng nhập Admin.
2. Gửi yêu cầu cập nhật trạng thái đơn hàng từ `pending` sang `shipping` (nhảy qua `confirmed`).
3. Kiểm tra thông tin đơn hàng sau khi gửi yêu cầu.

## Expected results
1. Hệ thống từ chối yêu cầu, trả về thông báo lỗi chuyển đổi trạng thái không hợp lệ.
2. Trạng thái đơn hàng giữ nguyên là `pending`.

## Actual results
1. Gửi yêu cầu cập nhật đơn hàng từ pending sang shipping.
2. Hệ thống báo lỗi "Invalid state transition from pending to shipping" với HTTP status 400.
3. Trạng thái đơn hàng giữ nguyên là pending.
