## Detail
| ID | Test Objective | Scenario Path | Kết quả mong đợi |
|---|---|---|---|
| FR10-UCT-02 | Người dùng tự hủy đơn hàng thành công khi đơn hàng đang ở trạng thái pending | AF1: AF1.1 -> AF1.2 -> AF1.3 | Đơn hàng chuyển sang trạng thái `canceled` thành công |

## Preconditions
1. Người dùng đã đăng nhập tài khoản User (`test@eshop.com` / `Test1234!`).
2. Có sẵn một đơn hàng của User ở trạng thái `pending`.
3. Đang ở trang Lịch sử đơn hàng của User.

## Test data
| Field | Value |
|---|---|
| Tài khoản User | `test@eshop.com` / `Test1234!` |
| Trạng thái ban đầu | `pending` |

## Test steps
1. Đăng nhập User và truy cập Lịch sử đơn hàng.
2. Tìm đơn hàng ở trạng thái `pending`.
3. Nhấp nút Hủy đơn hàng và xác nhận hủy.

## Expected results
1. Đăng nhập User thành công, hiển thị danh sách lịch sử đơn hàng.
2. Tìm thấy đơn hàng `pending` và có nút Hủy đơn hàng.
3. Đơn hàng chuyển sang trạng thái `canceled` thành công và nút Hủy đơn hàng biến mất (hoặc vô hiệu hóa).

## Actual results
1. Đăng nhập User thành công.
2. Tìm thấy đơn hàng pending và thực hiện hủy.
3. Đơn hàng chuyển sang trạng thái canceled thành công.
