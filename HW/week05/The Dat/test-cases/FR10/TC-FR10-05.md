## Detail
| ID | Test Objective | Scenario Path | Kết quả mong đợi |
|---|---|---|---|
| FR10-UCT-05 | Hệ thống chặn việc chuyển đổi trạng thái của đơn hàng từ delivered sang bất kỳ trạng thái nào khác | EF1: EF1.1 -> EF1.2 | Yêu cầu bị chặn, trả về lỗi, trạng thái giữ nguyên là `delivered` |

## Preconditions
1. Đăng nhập tài khoản Admin (`admin@eshop.com` / `Admin123!`).
2. Có đơn hàng test ở trạng thái `delivered` (trạng thái kết thúc).
3. Đang ở trang Admin / Quản lý đơn hàng hoặc sử dụng công cụ gửi request API.

## Test data
| Field | Value |
|---|---|
| Tài khoản Admin | `admin@eshop.com` / `Admin123!` |
| Trạng thái hiện tại | `delivered` |
| Trạng thái muốn chuyển | `pending` hoặc `confirmed` hoặc `shipping` hoặc `canceled` |

## Test steps
1. Gửi yêu cầu cập nhật trạng thái đơn hàng (qua UI hoặc API) từ `delivered` sang một trạng thái khác như `pending` hoặc `confirmed`.
2. Kiểm tra thông tin đơn hàng sau khi gửi yêu cầu.

## Expected results
1. Hệ thống từ chối yêu cầu, hiển thị thông báo lỗi phù hợp (hoặc trả về HTTP status 400 Bad Request kèm thông điệp lỗi nếu gọi API trực tiếp).
2. Trạng thái đơn hàng trong hệ thống/cơ sở dữ liệu giữ nguyên là `delivered`.

## Actual results
1. Gửi yêu cầu cập nhật đơn hàng từ delivered sang confirmed.
2. Hệ thống báo lỗi "Invalid state transition from delivered to confirmed" với HTTP status 400.
3. Trạng thái đơn hàng giữ nguyên là delivered.
