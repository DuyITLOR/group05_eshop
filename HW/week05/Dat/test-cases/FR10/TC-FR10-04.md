## Test steps
1. Đăng nhập Admin và truy cập trang quản lý đơn hàng.
2. Tìm đơn hàng ở trạng thái `pending` hoặc `confirmed`.
3. Nhấp chọn cập nhật trạng thái đơn hàng sang `canceled`.

## Expected results
1. Đăng nhập Admin thành công.
2. Tìm thấy đơn hàng đích.
3. Đơn hàng chuyển sang trạng thái `canceled` thành công.

## Actual results
1. Đăng nhập Admin thành công.
2. Tìm thấy đơn hàng pending/confirmed.
3. Đơn hàng chuyển sang trạng thái canceled thành công qua API của Admin.
