## Detail

|---|---|---|---|
| FR10-UCT-07 | Người dùng tự hủy đơn hàng thất bại khi đơn hàng đang ở trạng thái shipping | EF2: EF2.1 -> EF2.2 | Hệ thống chặn yêu cầu hủy của User, trạng thái giữ nguyên là `shipping` |

## Preconditions
1. Người dùng đã đăng nhập tài khoản User (`test@eshop.com` / `Test1234!`).
2. Có đơn hàng của User ở trạng thái `shipping` (đang giao hàng).
3. Đang ở trang Lịch sử đơn hàng của User hoặc sử dụng công cụ gửi request API.

## Test data
| Field | Value |
|---|---|
| Tài khoản User | `test@eshop.com` / `Test1234!` |
| Trạng thái hiện tại | `shipping` |

## Test steps
1. Đăng nhập User và truy cập Lịch sử đơn hàng.
2. Kiểm tra xem trên giao diện có hiển thị nút Hủy đơn hàng hay không.
3. Gửi yêu cầu hủy đơn hàng (hoặc qua nút bấm nếu có, hoặc gửi trực tiếp request `PUT /api/orders/:id/cancel`).
4. Kiểm tra trạng thái đơn hàng.

## Expected results
1. Giao diện lịch sử đơn hàng của User KHÔNG hiển thị nút Hủy đơn hàng cho đơn hàng đang ở trạng thái `shipping`.
2. Nếu cố tình gửi request API hủy đơn hàng trực tiếp, hệ thống phải từ chối yêu cầu, báo lỗi phù hợp.
3. Trạng thái đơn hàng giữ nguyên là `shipping`.

## Actual results
1. Gửi request API hủy đơn hàng đang ở trạng thái shipping bằng tài khoản User.
2. Hệ thống cho phép hủy thành công (mã 200 OK) thay vì chặn lại.
3. Trạng thái đơn hàng bị chuyển thành canceled.
