## Preconditions
1. Đăng nhập tài khoản Admin (`admin@eshop.com` / `Admin123!`).
2. Có sẵn một đơn hàng test ở trạng thái `pending`.
3. Đang ở trang Admin / Quản lý đơn hàng.

## Test data
| Field | Value |
|---|---|
| Tài khoản Admin | `admin@eshop.com` / `Admin123!` |
| Trạng thái ban đầu | `pending` |

## Test steps
1. Đăng nhập Admin và vào trang quản lý đơn hàng.
2. Tìm đơn hàng ở trạng thái `pending`.
3. Cập nhật trạng thái đơn hàng sang `confirmed`.
4. Tìm đơn hàng vừa cập nhật, chuyển trạng thái sang `shipping`.
5. Tìm đơn hàng đó, chuyển trạng thái sang `delivered`.

## Expected results
1. Đăng nhập Admin thành công, vào được trang quản lý đơn hàng.
2. Tìm thấy đơn hàng `pending`.
3. Đơn hàng chuyển sang trạng thái `confirmed` thành công.
4. Đơn hàng chuyển sang trạng thái `shipping` thành công.
5. Đơn hàng chuyển sang trạng thái `delivered` thành công và không thể chuyển đổi tiếp sang bất kỳ trạng thái nào khác.

## Actual results
1. Đăng nhập Admin thành công.
2. Tìm thấy đơn hàng pending.
3. Đơn hàng chuyển sang trạng thái confirmed thành công.
4. Đơn hàng chuyển sang trạng thái shipping thành công.
5. Đơn hàng chuyển sang trạng thái delivered thành công.
