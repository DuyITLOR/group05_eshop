## Preconditions
1. Đăng nhập tài khoản Admin (`admin@eshop.com` / `Admin123!`).
2. Có đơn hàng test ở trạng thái `canceled` (trạng thái kết thúc).
3. Đang ở trang Admin / Quản lý đơn hàng hoặc sử dụng công cụ gửi request API.

## Test data
| Field | Value |
|---|---|
| Tài khoản Admin | `admin@eshop.com` / `Admin123!` |
| Trạng thái hiện tại | `canceled` |
| Trạng thái muốn chuyển | `pending` hoặc `confirmed` hoặc `shipping` hoặc `delivered` |

## Test steps
1. Gửi yêu cầu cập nhật trạng thái đơn hàng từ `canceled` sang một trạng thái khác như `delivered`.
2. Kiểm tra thông tin đơn hàng sau khi gửi yêu cầu.

## Expected results
1. Hệ thống từ chối yêu cầu, hiển thị thông báo lỗi phù hợp (hoặc trả về HTTP status 400 Bad Request kèm thông điệp lỗi nếu gọi API trực tiếp).
2. Trạng thái đơn hàng trong hệ thống/cơ sở dữ liệu giữ nguyên là `canceled`.

## Actual results
1. Gửi yêu cầu cập nhật đơn hàng từ canceled sang delivered.
2. Hệ thống cập nhật thành công (mã 200 OK) thay vì chặn lại và báo lỗi.
3. Trạng thái đơn hàng bị chuyển thành delivered, vi phạm sơ đồ chuyển đổi trạng thái của đơn hàng kết thúc.
