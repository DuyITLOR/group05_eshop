# TC_UC_001 - Reset Password Successfully

## Technique
Use Case Testing

## Feature
FR-03: Quên mật khẩu & Đặt lại mật khẩu (2 bước)

## Objective
Verify the main success scenario for resetting a forgotten password.

## Preconditions
- User is on the Login Page.
- Account `test@eshop.com` exists.

## Test Data

| Field | Value |
|---|---|
| Email | `test@eshop.com` |
| OTP | OTP generated by the system |
| New Password | `NewPassword123!` |
| Confirm New Password | `NewPassword123!` |

## Steps

| Step | User Action | Expected System Response |
|---|---|---|
| 1 | Open the forgot password flow. | System displays Step 1 with email input, Step Indicator `Bước 1 / 2`, and `Quay lại đăng nhập`. |
| 2 | Enter `test@eshop.com` and submit. | System creates a 6-digit OTP through `POST /api/forgot-password`. |
| 3 | Continue to the reset step. | System displays OTP, new password, and confirm new password fields. |
| 4 | Enter valid OTP, `NewPassword123!`, and matching confirmation. | System accepts the reset data. |
| 5 | Submit the reset form. | System updates the password through `POST /api/reset-password`. |

## Expected Result
Password is reset successfully.

Main Success Scenario
